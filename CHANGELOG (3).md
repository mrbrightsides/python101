# 📝 Changelog

All notable changes to Python 101 – Dasar-dasar will be documented in this file.

## [1.0.0] - 2024-10-09

### 🎉 Initial Release

#### ✨ Added

**Core Learning Features:**
- 6 fundamental Python modules (Syntax, Variables, I/O, Operators, Conditions, Loops)
- Interactive code editor powered by Pyodide for real Python execution in browser
- Comprehensive quiz system with 5 questions per module
- Detailed explanations and instant feedback for quizzes
- Tutorial content with markdown support and code examples
- Practice exercises for hands-on learning

**Gamification System:**
- Level progression system (Pemula → Python Master)
- Point tracking with multiple earning opportunities
- 5 achievement badges (First Steps, Dedicated Learner, Quiz Master, Module Master, Python Graduate)
- Streak counter for consistent learning
- Visual progress indicators and statistics

**User Interface:**
- Web3-themed animated particle background
- Modern gradient design (cyan/purple color scheme)
- Responsive layout for desktop and mobile
- Tab-based navigation (Tentang, Modul, Saran, Referensi)
- Welcome screen with personalized greeting
- Progress tracker sidebar with real-time updates

**Technical Features:**
- LocalStorage integration for automatic progress saving
- TypeScript for type-safe development
- Next.js 14 with App Router
- Tailwind CSS for utility-first styling
- shadcn/ui component library
- Client-side Python execution with Pyodide

**Documentation:**
- Comprehensive README.md with installation guide
- Contributing guidelines (CONTRIBUTING.md)
- MIT License
- Code of conduct for contributors
